# 扩展功能测试资源（ext-test）

用于测试答题小站的「扩展商店」各功能。在扩展卡片里点「从仓库选择…」，
输入 `lichenyu27/try`、分支 `main` 即可浏览到 `ext-test/` 下的这些文件。

| 文件 / 文件夹 | 用途 | 建议用法 |
|---|---|---|
| `bg/` | 3 张背景图（bg1/bg2/bg3） | 选单张=固定背景；选整个 `bg/` 文件夹=每 30 秒轮换一张 |
| `music/` | 2 段短音频（song1/song2，频率不同便于区分） | 选单首=循环；选整个 `music/` 文件夹=顺序播放，一首放完自动切下一首 |
| `lcd.json` | LCD 像素屏滚动文本（content / lines 两种写法） | LCD 附加：选此 JSON，屏幕上快速滚动 |
| `seats.json` | 自动点名座位图（每行人数 + 走道 + 姓名） | 自动点名：选此 JSON，下一题前随机点一人 |

配合仓库根目录的 `quiz-*.json` 题库开始答题，即可看到各扩展效果。
